# Deepak Kartik Karuppusamy — Personal Website

A responsive, dependency-free personal portfolio built with HTML, CSS, and
JavaScript.

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser.

## Customize

- Update biography, career details, and education in `index.html`.
- Change the visual theme using the variables at the top of `portfolio.css`.
- Add an email address, resume, project links, or profile photo when available.
